# 设计稿与素材

前端设计资源统一放这里，**不会打进 App 包体**，仅供对照开发与归档。

## 目录

| 目录 | 用途 |
|------|------|
| `mockups/` | 页面设计稿（按模块分子目录：home、cabinet、workbench、profile） |
| `source/` | 源文件（Figma 导出工程、PSD、Sketch、SVG 源稿等） |
| `exports/` | 给开发用的切图导出（按页面或功能命名） |
| `references/` | 参考图、竞品截图、灵感收集 |

## 与运行时素材的区别

- **设计归档** → 本目录 `frontend/design/`
- **App 实际引用** → `frontend/apps/app-rn/assets/`（见该目录 README）

## 命名建议

```
mockups/home/首页-v2.png
exports/home-logo-card@2x.png
exports/home-logo-card@3x.png
```
