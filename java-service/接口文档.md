# Java 业务服务 —— 接口文档

> 对应服务：`java-service`  
> 业务说明见 [`README.md`](./README.md)  
> 版本：v0.1（MVP 约定稿，脚手架落地前以本文为准）

约定：

- Base URL（本地）：`http://127.0.0.1:8080`
- 除注册 / 登录外，请求头：`Authorization: Bearer <access_token>`（Swagger 登录后也可依赖 Cookie `ACCESS_TOKEN`）
- JSON；流式为 `text/event-stream`（SSE）
- APP **只调用本文 Java 接口**；AI 能力由 Java 转发 Python
- **额度相关接口不做**

### 统一响应体

除 SSE 流式接口外，成功/失败均使用：

```json
{
  "success": true,
  "status": 200,
  "code": "OK",
  "message": null,
  "data": { }
}
```

| 字段 | 说明 |
| --- | --- |
| `status` | 数字状态码，与 HTTP Status 一致（200 / 400 / 401 / 403 / 500…） |
| `code` | 业务码字符串（`OK`、`UNAUTHORIZED`、`CABINET_EMPTY`…） |
| `message` | 给人看的说明；成功常为 null |
| `data` | 业务数据；失败为 null |

失败示例（未登录）：

```json
{
  "success": false,
  "status": 401,
  "code": "UNAUTHORIZED",
  "message": "未登录或 Token 无效，请先调用 /api/cocktail/auth/login",
  "data": null
}
```

HTTP 响应头里的 Status 与 body 里的 `status` 保持一致。

## 2. 材料目录 `/api/cocktail/ingredients`

供酒柜「新增库存」与工作台「选材料」共用。数据只读自 `kb_ingredient`。

### `GET /api/cocktail/ingredients/categories`

```json
{
  "categories": [
    {
      "code": "基酒",
      "name": "基酒",
      "children": [
        { "code": "威士忌", "name": "威士忌" },
        { "code": "伏特加", "name": "伏特加" },
        { "code": "金酒", "name": "金酒" },
        { "code": "朗姆", "name": "朗姆" },
        { "code": "龙舌兰", "name": "龙舌兰" }
      ]
    },
    { "code": "利口酒", "name": "利口酒", "children": [] },
    { "code": "糖浆", "name": "糖浆", "children": [] },
    { "code": "果汁/软饮", "name": "果汁/软饮", "children": [] },
    { "code": "新鲜材料", "name": "新鲜材料", "children": [] },
    { "code": "苦精", "name": "苦精", "children": [] },
    { "code": "装饰", "name": "装饰", "children": [] }
  ]
}
```

一级分类与 Python `CATEGORIES`、前端 `IngredientCategory` 保持一致。UI 文案「糖」映射为「糖浆」。

### `GET /api/cocktail/ingredients/search`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `q` | 否 | 模糊匹配 `name` / `name_en`（品牌、品名） |
| `category` | 否 | 一级分类；不传则全库 |
| `sub_category` | 否 | 二级；「全部」不传 |
| `page` | 否 | 默认 1 |
| `size` | 否 | 默认 20 |

```json
{
  "items": [
    {
      "id": 101,
      "name": "孟买蓝宝石金酒",
      "name_en": "Bombay Sapphire",
      "category": "基酒",
      "sub_category": "金酒",
      "primary_unit": "ml",
      "image_url": "https://..."
    }
  ],
  "total": 42,
  "page": 1,
  "size": 20
}
```

仅填 `q` 时跨全部分类模糊搜索。

## 3. 酒柜 `/api/cocktail/cabinet`

### `GET /api/cocktail/cabinet`

| 参数 | 说明 |
| --- | --- |
| `q` | 在**本人库存**内模糊搜品牌/类别/名称 |
| `category` / `sub_category` | 分类筛选 |
| `page` / `size` | 分页 |

```json
{
  "summary": { "item_count": 1 },
  "items": [
    {
      "id": 1,
      "ingredient_id": 101,
      "name": "孟买蓝宝石金酒",
      "name_en": "Bombay Sapphire",
      "category": "基酒",
      "sub_category": "金酒",
      "quantity": 750,
      "unit": "ml",
      "quantity_known": true,
      "stock_status": "in_stock",
      "image_url": "...",
      "created_at": "2026-10-26T12:00:00Z"
    }
  ],
  "total": 1
}
```

`quantity_known: false` 时前端可展示「余量未知」。

### `POST /api/cocktail/cabinet`

单条或批量添加；`ingredient_id` 必须已存在于知识库。

```json
// request
{
  "merge": true,
  "items": [
    {
      "ingredient_id": 101,
      "quantity": 750,
      "unit": "ml",
      "quantity_known": true
    }
  ]
}
```

`merge: true`：同一用户已有该材料则更新/累加；`false`：冲突则 409。

### `PUT /api/cocktail/cabinet/{id}`

```json
{
  "quantity": 500,
  "unit": "ml",
  "quantity_known": true
}
```

### `DELETE /api/cocktail/cabinet/{id}`

删除一条库存。

### `POST /api/cocktail/cabinet/recognize`

拍照批量识别。`multipart/form-data`，字段名 `file`。

流程：Java → Python 识图 → Java 匹配 `kb_ingredient` → 只返回库内命中项。

```json
{
  "matched": [
    {
      "ingredient_id": 101,
      "name": "孟买蓝宝石金酒",
      "name_en": "Bombay Sapphire",
      "category": "基酒",
      "sub_category": "金酒",
      "image_url": "...",
      "confidence": 0.92,
      "already_in_cabinet": false
    }
  ],
  "unmatched": [
    { "raw_label": "某小众酒", "reason": "not_in_catalog" }
  ]
}
```

用户勾选后仍调用 `POST /api/cocktail/cabinet` 写入。未匹配项不可入库。

### `POST /api/cocktail/cabinet/menu`

根据当前用户库存生成酒单。

```json
// request（均可选）
{
  "limit": 10,
  "diversity": true
}

// response
{
  "recipes": [
    {
      "recipe_id": 123,
      "name": "马丁尼",
      "name_en": "Martini",
      "category": "短饮",
      "base_spirit": "金酒",
      "glass": "马提尼杯",
      "method": "stir",
      "image_url": "...",
      "match_type": "full",
      "missing": [],
      "substitutes": []
    }
  ],
  "meta": {
    "requested": 10,
    "returned": 10,
    "cabinet_ingredient_count": 6
  }
}
```

| 约定 | 说明 |
| --- | --- |
| 默认 `limit` | **10** |
| `diversity` 默认 `true` | 基酒 / 品类 / 技法尽量分散 |
| `match_type` | `full` 全匹配 / `partial` 有缺料 |

Java 组装库存快照后调 Python 向量检索。

## 4. 调配工作台 `/api/cocktail/workbench`

### `GET /api/cocktail/workbench/glasses`

```json
{
  "items": [
    {
      "code": "flute",
      "name": "香槟杯",
      "name_en": "Flute",
      "capacity_ml": 125,
      "image_url": "..."
    }
  ]
}
```

### `GET /api/cocktail/workbench/options`

```json
{
  "methods": [
    { "code": "build", "name": "杯中直调", "name_en": "Build" },
    { "code": "stir", "name": "搅拌", "name_en": "Stir" },
    { "code": "shake", "name": "摇和", "name_en": "Shake" },
    { "code": "layer", "name": "分层", "name_en": "Layer" }
  ],
  "ice_types": [
    { "code": "none", "name": "无冰" },
    { "code": "less", "name": "少冰" },
    { "code": "standard", "name": "标准冰" },
    { "code": "crushed", "name": "碎冰" },
    { "code": "large", "name": "大冰块" }
  ],
  "garnishes": [
    { "code": "basil", "name": "罗勒", "image_url": "..." },
    { "code": "lemon_twist", "name": "柠檬皮卷", "image_url": "..." }
  ],
  "limits": { "max_ingredients": 12 }
}
```

材料列表仍用 `/api/cocktail/ingredients/search`。

### `POST /api/cocktail/workbench/sessions`

创建一局草稿。

```json
{
  "session_id": "uuid",
  "status": "draft",
  "glass": null,
  "ingredients": [],
  "method": null,
  "ice_type": null,
  "garnishes": [],
  "feeling": null,
  "volume_ml": 0,
  "capacity_ml": null,
  "remaining_ml": null,
  "ingredient_count": 0,
  "max_ingredients": 12
}
```

### `GET /api/cocktail/workbench/sessions/{session_id}`

查询草稿（完整快照，字段同上）。

### `PATCH /api/cocktail/workbench/sessions/{session_id}`

按步更新，只传变更字段；响应为完整快照。

选杯：

```json
{ "glass_code": "flute" }
```

材料（全量覆盖已选列表）：

```json
{
  "ingredients": [
    { "ingredient_id": 101, "amount": 45, "unit": "ml" }
  ]
}
```

校验：条数 ≤ `max_ingredients`；用量合计 ≤ 杯 `capacity_ml`，否则 400。

技法 / 冰 / 装饰 / 感觉：

```json
{
  "method": "build",
  "ice_type": "standard",
  "garnishes": ["basil", "lemon_twist"],
  "feeling": "清爽一点，不要太甜"
}
```

### `POST /api/cocktail/workbench/sessions/{session_id}/reset`

```json
{ "keep_glass": true }
```

清空材料与后续选项；`keep_glass: true` 时保留已选杯。

### `POST /api/cocktail/workbench/sessions/{session_id}/analyze`

成杯可行性（JSON）。Java 提交当前 session → Python。

```json
{
  "feasible": true,
  "flavor_summary": "偏干、柑橘香、酒体中等",
  "conflicts": [
    { "level": "warn", "message": "咖啡与柠檬酸易苦涩，建议调整比例" }
  ],
  "suggestions": ["可补一点糖浆平衡酸度"]
}
```

### `POST /api/cocktail/workbench/sessions/{session_id}/generate`

生成特调。Body 可选覆盖 `feeling`。响应建议 SSE（与对话对齐）：

| 事件 `type` | 说明 |
| --- | --- |
| `token` | 流式文案 |
| `recipe` | 结构化操作卡（名称、材料、技法、冰、杯、装饰、步骤等） |
| `source` | 溯源 |
| `done` / `error` | 结束 / 失败 |

## 5. 对话 `/api/cocktail/chat`

首页 RAG 问答、风味 DIY 追问。

### `POST /api/cocktail/chat`

```json
// request
{
  "thread_id": "uuid",
  "user_input": "清爽一点的短饮推荐",
  "attach_cabinet": true,
  "context": { "mode": "home" }
}
```

`attach_cabinet: true` 时 Java 自动附带当前用户酒柜快照。响应：SSE。

### `POST /api/cocktail/chat/resume`

```json
{
  "thread_id": "uuid",
  "user_input": "酸味突出"
}
```

同一 `thread_id` 续聊。响应：SSE。

### SSE 事件（Python → Java → APP）

```json
{"type": "token", "content": "根据你的库存"}
{"type": "source", "source": "mixmyth", "recipe_id": "123"}
{"type": "interrupt", "question": "偏向哪种口感？", "options": ["气泡", "偏酸", "偏苦"]}
{"type": "done"}
```

## 6. Java → Python 契约（服务间）

配置：`cocktail.ai.base-url`（默认 `http://127.0.0.1:8000`）。  
Python 侧扩展稳定接口（契约 A）；管理页旧接口可保留。

### 6.1 对话

- `POST {base}/api/ai/chat`（或与现网对齐的 path）
- `POST {base}/api/ai/chat/resume`

```json
{
  "thread_id": "uuid",
  "user_input": "我的酒柜能做什么",
  "cabinet_snapshot": [
    {
      "name": "金酒",
      "name_en": "Gin",
      "category": "基酒",
      "quantity": 500,
      "unit": "ml"
    }
  ],
  "context": { "mode": "cabinet" }
}
```

响应：SSE，事件形态与第 5 节一致。

### 6.2 材料识图

- `POST {base}/api/ai/ingredients/recognize`（`multipart` 图片）

```json
{
  "labels": [
    { "name": "孟买蓝宝石", "name_en": "Bombay Sapphire", "confidence": 0.92 }
  ]
}
```

Java 负责用标签匹配 `kb_ingredient`。

### 6.3 库存酒单

- `POST {base}/api/ai/cabinet/menu`

```json
{
  "cabinet_snapshot": [ /* 同对话快照 */ ],
  "limit": 10,
  "diversity": true
}
```

响应：配方列表（字段对齐 `POST /api/cocktail/cabinet/menu` 的 `recipes`）。

### 6.4 工作台分析 / 生成

- `POST {base}/api/ai/workbench/analyze` → JSON（可行性）
- `POST {base}/api/ai/workbench/generate` → SSE（特调）

请求体为工作台 session 快照（杯、材料用量、技法、冰、装饰、feeling）。

## 7. 工程与配置（实施备忘）

### 技术栈与包结构

- **Spring Boot 3.4.x** + **Java 17** + **Maven**
- **MyBatis-Plus**（分页插件、自动填充 `created_at` / `updated_at`）
- 业务表：`src/main/resources/schema.sql`

```text
java-service/
├── pom.xml
├── README.md
├── 接口文档.md
└── src/main/java/com/cocktail/
    ├── CocktailApplication.java
    ├── config/          # Security、WebClient、MybatisPlus
    ├── shared/          # exception、security、web
    ├── user/            # domain + mapper + api
    ├── ingredient/
    ├── cabinet/
    ├── workbench/
    ├── chat/            # 含 client.AiServiceClient
    └── community/       # P2 空包
```

### 配置要点

```yaml
server:
  port: 8080

spring:
  datasource:
    url: jdbc:postgresql://${POSTGRES_HOST:127.0.0.1}:${POSTGRES_PORT:5432}/${POSTGRES_DB:cocktail}
    username: ${POSTGRES_USER:cocktail}
    password: ${POSTGRES_PASSWORD:cocktail}
  sql:
    init:
      mode: always
      schema-locations: classpath:schema.sql

mybatis-plus:
  configuration:
    map-underscore-to-camel-case: true
  global-config:
    db-config:
      id-type: auto

cocktail:
  jwt:
    secret: ${JWT_SECRET:change-me}
    access-ttl-minutes: 30
    refresh-ttl-days: 14
  ai:
    base-url: ${AI_SERVICE_URL:http://127.0.0.1:8000}
```

### 本地启动

```bash
docker compose up -d
# ai-service: uvicorn app.main:app --host 0.0.0.0 --port 8000
cd java-service && mvn spring-boot:run
```

健康检查：`GET /actuator/health`。  
Swagger UI：`http://127.0.0.1:8080/swagger-ui.html`  
登录成功后浏览器会保存 Cookie `ACCESS_TOKEN`，Swagger 同源 Try it out 会自动带上；也可用右上角 Authorize 填 Bearer JWT。

### Java 侧主要表

| 表 | 用途 |
| --- | --- |
| `app_user` | 用户 |
| `refresh_token` | 刷新令牌 |
| `cabinet_item` | 酒柜；含 `ingredient_id`、`quantity_known` 等 |
| `workbench_session` / `workbench_session_item` | 调配草稿（item 外键列名 `session_pk`） |
| 杯型等 | MVP 配置类 `WorkbenchCatalog` |

不建额度表。`kb_*` 由 Python 维护。
